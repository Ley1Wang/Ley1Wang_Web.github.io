What the counters mean

Comparisons count comparisons between data values, including the final unsuccessful comparison in insertion sort. Array writes count assignments to array positions: a swap uses two writes; an insertion shift uses one. Loop tests and temporary variables are not counted. Reset keeps the input and comparison results; shuffle or a size change starts a new comparison. Animation delay is not a runtime benchmark.
